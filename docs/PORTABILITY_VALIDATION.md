# Portable runtime validation / Validacao global do runtime portatil

## Scope / Escopo

**EN:** This document separates verified standalone behavior from unverified game
integration. All changes belong to the **portable** branch; licensed Sonic Unleashed
game assets are **not** shipped, mirrored, or generated by the test runner.

**PT-BR:** Este documento separa contratos comprovados dos comportamentos do jogo
que ainda precisam de validacao. Todas as alteracoes ficam em **portable**;
arquivos licenciados do Sonic Unleashed **nao** acompanham os testes.

## Reproducible tests / Testes reproduziveis

The default script executes Debug and Release standalone CMake tests.

O script padrao executa os testes independentes em Debug e Release.

~~~bash
bash tools/validate-portable-runtime.sh
bash tools/validate-portable-runtime.sh --sanitizers
git submodule update --init --recursive tools/XenonRecomp tools/XenosRecomp
bash tools/validate-portable-runtime.sh --host-tools
~~~

**EN:** Host generators should use Clang because the XenonRecomp submodule
contains C++ anonymous aggregates that GCC rejects. The portability layer does
not rewrite the external project's source.

**PT-BR:** Os geradores devem usar Clang: o submodulo XenonRecomp contem
agregados anonimos C++ rejeitados pelo GCC. A camada portatil nao modifica
o codigo do projeto externo.

## Full Linux game build / Build completo do jogo no Linux

**EN:** The `linux-debug` preset already defines `VCPKG_ROOT` as
`thirdparty/vcpkg`. The script now respects that setting and does not
require a separately exported shell variable. It checks for the vcpkg
submodule and its bootstrapped executable before compiling the game.

**PT-BR:** O preset `linux-debug` ja configura `VCPKG_ROOT` como
`thirdparty/vcpkg`. O script agora utiliza essa configuracao sem exigir
a variavel no shell e verifica se o submodulo e o vcpkg estao prontos.

~~~bash
git switch portable
git pull --ff-only
git submodule update --init --recursive
./thirdparty/vcpkg/bootstrap-vcpkg.sh
bash tools/validate-portable-runtime.sh --full
~~~

The build still requires legitimately obtained `default.xex`,
`default.xexp` and `shader.ar` in `UnleashedRecompLib/private/`.
O build exige esses tres arquivos da copia licenciada do jogo.

**EN:** The script reports `BLOCKED` with an actionable command if
vcpkg is uninitialized. Success here does not prove full gameplay stability.

**PT-BR:** A ausencia do vcpkg gera `BLOCKED` com a solucao indicada.
A compilacao bem-sucedida ainda nao comprova estabilidade no gameplay.

## CI interpretation / Como interpretar os testes

- **Linux / Windows Debug+Release:** asset-free tests, no guest game data.
- **Linux ASan+UBSan:** detects invalid accesses and undefined behavior in
  covered portable paths, **not** full guest gameplay.
- **Linux host generators:** tests compiler toolchains; it neither generates
  original game content nor builds the complete engine.
- **macOS:** manual job until a macOS runner is available; page sizes >4 KiB
  need a memory compatibility strategy, not a silent workaround.

**EN:** The "portable" branch is a stable integration baseline only after each
target's full build and real gameplay tests succeed. Do not describe these
standalone checks as a finished Switch or Android port.

**PT-BR:** A branch "portable" so sera considerada validada integralmente para
cada destino apos build completo e testes reais. Testes de infraestrutura
nao representam ports Switch ou Android concluidos.

## Linux GTK 3 dependency / Dependencia GTK 3 no Linux

**EN:** The Linux desktop `nativefiledialog-extended` backend requires the
`gtk+-3.0` pkg-config development module. Running only the asset-free
portable unit tests does not check GUI dependencies. The `--full` runner
now checks GTK 3 before invoking the full game CMake configuration.

**PT-BR:** O backend Linux de `nativefiledialog-extended` exige o modulo
`gtk+-3.0` do pkg-config. Testes independentes do runtime nao verificam
as dependencias da interface grafica. A opcao `--full` agora verifica
o GTK 3 antes de iniciar o CMake do jogo.

~~~bash
# Ubuntu / Debian / Mint
sudo apt install libgtk-3-dev
# Fedora
sudo dnf install gtk3-devel
# Arch / Manjaro
sudo pacman -S gtk3

pkg-config --modversion gtk+-3.0
bash tools/validate-portable-runtime.sh --full
~~~

**EN:** The top-level CMake configuration sets `CMAKE_POLICY_DEFAULT_CMP0077`
to `NEW` to prevent older nested projects from warning about `option()`
overriding normal variables. No vendored library is modified.

**PT-BR:** O CMake principal define `CMAKE_POLICY_DEFAULT_CMP0077` como
`NEW` para evitar avisos de `option()` em subprojetos antigos, sem modificar
o codigo das bibliotecas de terceiros.
