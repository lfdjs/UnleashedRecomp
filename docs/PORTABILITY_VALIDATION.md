# Portable runtime validation / Validacao global do runtime portatil

## Scope / Escopo

**EN:** This document separates verified standalone behavior from unverified game
integration. All changes belong to the **portable** branch; licensed Sonic Unleashed
game assets are **not** shipped, mirrored, or generated by the test runner.

**PT-BR:** Este documento separa contratos comprovados dos comportamentos do jogo
que ainda precisam de validacao. Todas as alteracoes ficam em **portable**;
arquivos licenciados do Sonic Unleashed **nao** acompanham os testes.

## Layer status / Situacao por camada

| Layer | Code integrated / Integracao | Asset-free verification / Teste independente | Hardware proof / Prova no hardware |
|---|---|---|---|

| Storage and user paths | Yes / Sim | Directory creation and user-root smoke checks | Android sandbox pending |

| Graphics (Plume/Vulkan) | Existing renderer preserved | API metadata only | Vulkan device/swapchain/shaders pending |

## Reproducible tests / Testes reproduziveis

The default script executes Debug and Release standalone CMake tests.

O script padrao executa os testes independentes em Debug e Release.

~~~bash
bash tools/validate-portable-runtime.sh
bash tools/validate-portable-runtime.sh --sanitizers
git submodule update --init --recursive tools/XenonRecomp tools/XenosRecomp
bash tools/validate-portable-runtime.sh --host-tools
~~~

**EN:** Host generators should use Clang because the XenonRecomp submodule
contains C++ anonymous aggregates that GCC rejects. The portability layer does
not rewrite the external project's source.

**PT-BR:** Os geradores devem usar Clang: o submodulo XenonRecomp contem
agregados anonimos C++ rejeitados pelo GCC. A camada portatil nao modifica
o codigo do projeto externo.

## Full Linux game build / Build completo do jogo no Linux

**EN:** The `linux-debug` preset already defines `VCPKG_ROOT` as
`thirdparty/vcpkg`. The script now respects that setting and does not
require a separately exported shell variable. It checks for the vcpkg
submodule and its bootstrapped executable before compiling the game.

**PT-BR:** O preset `linux-debug` ja configura `VCPKG_ROOT` como
`thirdparty/vcpkg`. O script agora utiliza essa configuracao sem exigir
a variavel no shell e verifica se o submodulo e o vcpkg estao prontos.

~~~bash
git switch portable
git pull --ff-only
git submodule update --init --recursive
./thirdparty/vcpkg/bootstrap-vcpkg.sh
bash tools/validate-portable-runtime.sh --full
~~~

The build still requires legitimately obtained `default.xex`,
`default.xexp` and `shader.ar` in `UnleashedRecompLib/private/`.
O build exige esses tres arquivos da copia licenciada do jogo.

**EN:** The script reports `BLOCKED` with an actionable command if
vcpkg is uninitialized. Success here does not prove full gameplay stability.

**PT-BR:** A ausencia do vcpkg gera `BLOCKED` com a solucao indicada.
A compilacao bem-sucedida ainda nao comprova estabilidade no gameplay.

## CI interpretation / Como interpretar os testes

- **Linux / Windows Debug+Release:** asset-free tests, no guest game data.
- **Linux ASan+UBSan:** detects invalid accesses and undefined behavior in
  covered portable paths, **not** full guest gameplay.
- **Linux host generators:** tests compiler toolchains; it neither generates
  original game content nor builds the complete engine.
- **macOS:** manual job until a macOS runner is available; page sizes >4 KiB
  need a memory compatibility strategy, not a silent workaround.

**EN:** The "portable" branch is a stable integration baseline only after each
target's full build and real gameplay tests succeed. Do not describe these
standalone checks as a finished Switch or Android port.

**PT-BR:** A branch "portable" so sera considerada validada integralmente para
cada destino apos build completo e testes reais. Testes de infraestrutura
nao representam ports Switch ou Android concluidos.

## Linux GTK 3 dependency / Dependencia GTK 3 no Linux

**EN:** The Linux desktop `nativefiledialog-extended` backend requires the
`gtk+-3.0` pkg-config development module. Running only the asset-free
portable unit tests does not check GUI dependencies. The `--full` runner
now checks GTK 3 before invoking the full game CMake configuration.

**PT-BR:** O backend Linux de `nativefiledialog-extended` exige o modulo
`gtk+-3.0` do pkg-config. Testes independentes do runtime nao verificam
as dependencias da interface grafica. A opcao `--full` agora verifica
o GTK 3 antes de iniciar o CMake do jogo.

~~~bash
# Ubuntu / Debian / Mint
sudo apt install libgtk-3-dev
# Fedora
sudo dnf install gtk3-devel
# Arch / Manjaro
sudo pacman -S gtk3

pkg-config --modversion gtk+-3.0
bash tools/validate-portable-runtime.sh --full
~~~

**EN:** The top-level CMake configuration sets `CMAKE_POLICY_DEFAULT_CMP0077`
to `NEW` to prevent older nested projects from warning about `option()`
overriding normal variables. No vendored library is modified.

**PT-BR:** O CMake principal define `CMAKE_POLICY_DEFAULT_CMP0077` como
`NEW` para evitar avisos de `option()` em subprojetos antigos, sem modificar
o codigo das bibliotecas de terceiros.

## Vendor GUI compilation warnings / Avisos de compilacao das bibliotecas de interface

**EN:** The Linux x64 user build of 2026-11-21 reached `[143/143] Linking CXX executable`.
The supplied compiler excerpt recorded 49 warnings, all `-Wnontrivial-memcall`,
triggered by upstream Dear ImGui headers and their use by ImPlot.
This diagnostic concerns use of `memset`/`memcpy` on non-trivially copyable C++
types. It is not proof of an actual runtime defect, but it should not be
silenced globally.

**PT-BR:** O build Linux x64 chegou a `[143/143] Linking CXX executable`.
O log recebido registrou 49 warnings, todos `-Wnontrivial-memcall`,
originados em codigo upstream do Dear ImGui, inclusive na compilacao do ImPlot.
O aviso aborda `memset`/`memcpy` em tipos C++ nao trivialmente copiaveis;
nao prova defeito durante execucao, mas nao deve ser desabilitado globalmente.

The main-game CMake target now **only for Clang**, and **only for the nine
vendor ImGui/ImPlot translation units**, adds `-Wno-nontrivial-memcall`.
The upstream third-party submodules are untouched; other compiler warnings
remain enabled for the game, Plume, portable modules and other dependencies.

O CMake principal aplica `-Wno-nontrivial-memcall` **somente com Clang**
e **somente aos nove arquivos .cpp externos do ImGui/ImPlot**.
Os submodulos upstream permanecem intactos; os demais avisos seguem
ativos para o jogo, Plume, runtime e outras dependencias.

**PT-BR:** A alteracao apenas reduz avisos repetidos, sem garantir que as

## Linux host preflight and gameplay report / Diagnostico e relatorio de gameplay Linux

**EN:** Following a successful full Linux build, `--portable-preflight` checks
the already-reserved guest address space, configured user data directory, SDL
video/audio initialization, Vulkan loader visibility and controller discovery.
It exits **before** the installer, update checker, mod loader, game asset loading
or GPU pipeline creation. It does not write saves or change game settings.

**PT-BR:** Apos compilar o jogo, a opcao `--portable-preflight` verifica
a memoria guest, o caminho do usuario, inicializacao SDL de video/audio,
o carregador Vulkan e a descoberta de controles. Ela termina **antes** do
instalador, atualizador, carregamento dos arquivos do jogo ou pipeline GPU.
Nao altera saves nem configuracoes.

~~~bash
git switch portable
git pull --ff-only
cmake --build out/build/linux-debug --target UnleashedRecomp --parallel 4

# Check the host and save a report / Verifica o host e salva relatorio
bash tools/validate-linux-runtime.sh

# Then start the actual game and record stdout / Inicia o jogo e coleta log
bash tools/validate-linux-runtime.sh --game
~~~

Reports are written to `build/portable-runtime-reports/` by default.
Os relatorios sao salvos em `build/portable-runtime-reports/` por padrao.

**EN:** Preflight exit status is a bitmask: `1=guest memory unavailable`,
`2=SDL video failure`, `4=Vulkan loader failure`, `8=SDL audio failure`,
`16=invalid user data root`. A missing physical controller is informational.
Video and Vulkan loader success do **not** validate the Plume swapchain,
GPU features, shader rendering or gameplay FPS.

**PT-BR:** O retorno do diagnostico utiliza bits: `1=memoria nao reservada`,
`2=falha SDL video`, `4=falha do loader Vulkan`, `8=falha SDL audio`,
`16=diretorio de dados ausente`. Nao ter controle conectado nao reprova.
Vulkan detectado **nao** garante que o Plume renderize corretamente.

**EN:** The game session is opt-in (`--game`) and has no automatic timeout.
The report may contain system paths and GPU/controller identifiers; review
it before publicly sharing. Test the menu and an actual stage, then close
the game normally to record its exit code.

**PT-BR:** A execucao do jogo e opcional (`--game`) e sem limite de tempo.
Os logs podem revelar caminhos e nomes de dispositivos; revise-os antes
de publicar. Teste menus e uma fase e feche o jogo normalmente.

## Ninja incremental CMake regeneration / Regeneracao incremental pelo Ninja

**EN:** CMake presets export `VCPKG_ROOT` for the initial configure only.
When `cmake --build out/build/linux-debug` invokes Ninja, the generator may
re-run CMake directly after a source or CMakeLists change. The old top-level
guard required the shell environment variable even though the configured
vcpkg toolchain path was already saved in `CMakeCache.txt`.

The new `cmake/ResolveVcpkgRoot.cmake` module runs **before `project()`**.
It preserves an explicit environment value, otherwise recovers the vcpkg root
from a cached `CMAKE_TOOLCHAIN_FILE`, or the bundled `thirdparty/vcpkg`
fallback. Host-only tools and Switch cross-builds remain exempt.
No third-party submodule files are modified.

**PT-BR:** Os presets exportam `VCPKG_ROOT` somente durante a configuracao.
Quando o Ninja regenera o CMake em um build incremental, essa variavel pode
nao existir, embora o toolchain esteja salvo no `CMakeCache.txt`.
O modulo `cmake/ResolveVcpkgRoot.cmake` e executado **antes de `project()`**;
prioriza a variavel explicita, depois o toolchain armazenado e, como ultima
opcao, o vcpkg embutido. Builds de ferramentas nativas e do Switch nao sao
alterados. Nenhum arquivo de submodulo externo foi modificado.

~~~bash
git switch portable
git pull --ff-only
bash tools/tests/test-vcpkg-regeneration.sh
cmake --build out/build/linux-debug --target UnleashedRecomp --parallel 4
~~~

The asset-free regression fixture tests preset-less generation, Ninja
regeneration, custom external toolchains, and explicit environment values.
O teste independente verifica configuracao sem preset, regeneracao Ninja,
toolchains externos e variaveis fornecidas manualmente.

## Crash investigation 2026-11-22 / Investigacao dos abortos 22/11/2026

**EN:** Two captured Linux reports both finished all asset-free checks with
`PORTABLE_PREFLIGHT_END|exit_code=0`, but the process exited 134 after
`terminate called without an active exception`. This is a **process teardown
failure**, distinct from SDL/Vulkan feature discovery. A normal return from the
diagnostic path invoked all global C++ destructors even though HostStartup was
never executed. The `--portable-preflight` command now flushes diagnostics and
uses `std::_Exit(status)` *only for this diagnostic*, after SDL_Quit, to avoid
invoking destructors of game subsystems that were never started. Normal gameplay
shutdown is deliberately unchanged; its correctness has NOT been established.

**PT-BR:** Os dois relatorios registraram todas as verificacoes aprovadas,
mas o processo terminou com codigo 134 apos `terminate called without an
active exception`. E uma falha de **encerramento do processo**, independente
do sucesso ao detectar SDL/Vulkan. A opcao `--portable-preflight` agora
descarrega os buffers e utiliza `std::_Exit(status)` **apenas no diagnostico**,
depois de SDL_Quit, evitando destruidores de subsistemas nao inicializados.
Isso NAO comprova nem corrige o encerramento durante o gameplay.

**EN:** A separate game log aborted with GLib-GIO-ERROR while looking for
`antialiasing` under `org.gnome.settings-daemon.plugins.xsettings`.
The host had GTK 3 system libraries, NVIDIA 3060 Ti driver 580.178.04 and
Vulkan 1.4 loader. This log does NOT show successful Plume device creation.
GTK/GSettings version or environment mismatch is suspected, not proven.
The runtime report now includes **only presence**, not values, of potential
GTK/GIO/Snap environment overrides, and checks the public xsettings schemas.

**PT-BR:** O log do jogo abortou com GLib-GIO-ERROR ao consultar a chave
`antialiasing` no esquema `xsettings`. Isso indica incompatibilidade
possivel entre GTK/GSettings ou o ambiente herdado da IDE/Snap; os dados
ainda nao demonstram a origem exata. O relatorio agora registra somente a
presenca de variaveis relevantes, nao seus valores, alem dos esquemas
publicos para diagnosticar a diferenca.

git switch portable
git pull --ff-only
cmake --build out/build/linux-debug --target UnleashedRecomp --parallel 4
bash tools/validate-linux-runtime.sh
bash tools/validate-linux-runtime.sh --game
~~~
